# MONEY FLOW — личные финансы

Учёт доходов и расходов в тенге: счета разных банков, импорт выписок Kaspi / Halyk / Freedom / Jusan
с автоматической категоризацией, бюджет, цели, обучение финансовой грамотности.
Регистрация и облачная синхронизация через Supabase. Устанавливается на iPhone как приложение (PWA).

## Быстрый старт
- **Без установки:** `MoneyFlow.html` — двойной щелчок, работает в браузере (без облака).
- **Разработка:** нужен Node.js 20+ (https://nodejs.org, LTS).

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # тесты расчётов, импорта выписок и синхронизации
npm run build        # PWA для хостинга → dist/
npm run build:file   # один файл → dist-file/index.html
```

## Supabase (регистрация и облако)
1. supabase.com → New project (регион Frankfurt).
2. SQL Editor → вставьте `supabase/schema.sql` → Run. Создадутся таблицы и правила доступа (RLS).
3. Authentication → Sign In / Providers → Email: для теста выключите «Confirm email».
4. Authentication → URL Configuration: Site URL = адрес приложения (например `https://rakhambm.github.io/money-flow/`),
   добавьте его же в Redirect URLs — нужно для письма «восстановить пароль».
5. Скопируйте `.env.example` в `.env.production`, вставьте Project URL и anon/publishable key.

Без этих переменных приложение работает только на устройстве.

## iPhone
1. Приложение публикуется на GitHub Pages автоматически (`.github/workflows/deploy.yml`) при каждом push в `main`.
   Один раз: репозиторий → Settings → Pages → Source: **GitHub Actions**.
2. На iPhone откройте адрес в **Safari** → кнопка «Поделиться» → **«На экран Домой»**.
3. Запускайте с иконки: полноэкранный режим, работает без интернета, изменения отправятся в облако при появлении сети.

## Импорт выписок
- **Kaspi:** Kaspi.kz → Kaspi Gold → Выписка → PDF → «Сохранить в Файлы» → в приложении «Импорт выписки».
- **Другие банки:** выписка в Excel/CSV, колонки определяются автоматически (можно поправить вручную).
- Каждой операции назначается категория: сначала по вашим правилам, затем по словарю мерчантов
  Казахстана (Magnum, Small, Yandex Go, Alseco, Wildberries…). Исправите категорию — приложение запомнит
  магазин и предложит применить ко всем похожим операциям.
- Повторный импорт той же выписки не создаёт дублей (отпечаток операции `externalId`).
- Файл выписки разбирается на устройстве и никуда не отправляется.

## Структура
```
src/
  lib/
    calc.ts           все финансовые расчёты (тиыны, целые числа)
    bankImport.ts     разбор PDF Kaspi, Excel/CSV, суммы и даты
    categorize.ts     автокатегоризация + обучение правилам
    sync.ts           синхронизация с Supabase (очередь, diff, загрузка)
    supabase.ts       клиент Supabase
  store/
    AppStore.tsx      состояние приложения
    Cloud.tsx         вход, регистрация, синхронизация
  components/         ImportWizard, Accounts, AuthScreen, формы
  pages/              Главная, Операции, Аналитика, Бюджет, Цели, Обучение, Профиль
supabase/schema.sql   таблицы + RLS
```

## Как устроена синхронизация
Local-first: приложение всегда работает с данными на устройстве. Каждое изменение попадает в очередь
(хранится на устройстве), очередь отправляется в Supabase, когда есть сеть. При входе и при возвращении
в приложение загружаются свежие данные из облака. При первом входе можно перенести данные
с устройства в аккаунт или начать с нуля.

## App Store (на будущее)
Для публикации в App Store нужен аккаунт Apple Developer ($99/год). Этот же код можно упаковать
в нативное приложение через Capacitor и собрать в облаке (Codemagic / Ionic Appflow) без Mac.
